# Jyothy Labs Financial Valuation Engine

This project provides a professional-grade valuation analysis for Jyothy Labs.

## Contents
- **dcf_model.py**: A Python-based automated DCF engine built for high-speed valuation scenarios.
- **app.py**: An interactive web-based dashboard built with Streamlit for real-time sensitivity analysis.
- **requirements.txt**: Dependencies for environment setup.

## Technical Skills Used
- **Financial Modeling**: 3-Statement DCF, Terminal Value (Gordon Growth), and EV/Equity Bridge.
- **Programming**: Python (pandas, streamlit) for automating complex financial computations.
